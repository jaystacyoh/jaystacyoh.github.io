# 1. 엔화·면세 빠른 계산기

일본 여행에서 쇼핑할 때 쓰는 미니 웹앱입니다. 설치나 로그인 없이 브라우저에서 바로 열립니다.

**바로 열기 → https://jaystacyoh.github.io/**

## 이런 걸 한 화면에서 계산합니다

- **환율**: `¥100 = ○○원`을 직접 입력하거나, 실시간 환율 버튼으로 오늘 환율을 불러옵니다. 불러오지 못하면 입력한 환율(기본 900원)로 계산하고 그 사실을 표시합니다.
- **환산**: 엔화를 넣으면 원화가, 원화를 넣으면 엔화가 바로 나옵니다. `+100¥` ~ `+10,000¥` 버튼으로 금액을 빠르게 더할 수 있습니다.
- **면세**: 입력한 금액이 세금 포함(税込)이면 10% 일반 물품과 8% 식품·음료의 면세가·환급액을, 세금 별도(税抜)이면 10%·8% 세금 포함 금액을 보여 줍니다. 5,000엔 면세 기준 충족 여부와 백화점 수수료 1.55% 공제도 반영합니다.
- **나눠 내기**: 1인당 금액을 2~6명 등 원하는 인원으로 나눕니다.
- **최근 계산**: 저장한 계산은 브라우저 안(localStorage)에만 남고, 전체 삭제할 수 있습니다.

## 참고

- 환율은 참고용입니다. 실제 카드 청구액은 카드사 환율과 해외이용 수수료에 따라 달라질 수 있습니다.
- 면세 기준(税抜 5,000엔)과 수수료율은 매장 정책에 따라 다를 수 있습니다.
- 계산은 모두 브라우저에서 이루어지며, 입력한 금액이 서버로 전송되거나 수집되지 않습니다.
- 환율 조회에 [open.er-api.com](https://open.er-api.com/)의 공개 API를 사용합니다.

# 2. 청약 가점·예치금 계산기 (`/cheongyak/`)

민영주택 청약의 **가점 84점**과 **지역·전용면적별 청약 예치금** 충족 여부를 한 화면에서 계산합니다.

**바로 열기 → https://jaystacyoh.github.io/cheongyak/**

## 계산하는 것

- **무주택기간 (최대 32점)**: 기간을 직접 고르거나, 생년월일·혼인신고일·주택 처분 후 무주택일·공고일을 넣어 자동 계산합니다. 유주택이거나 만 30세 미만 미혼 무주택이면 0점입니다.
- **부양가족 수 (최대 35점, 본인 제외)**: 배우자·본인 직계존속·배우자 직계존속·미혼 직계비속을 따로 입력합니다. 0명 5점부터 6명 이상 35점까지입니다.
- **청약통장 가입기간 (최대 17점)**: 본인 가입기간에 배우자 가입기간의 50%(최대 3점)를 더하되, **합계 17점을 넘지 않습니다**. 미성년 가입기간은 5년까지만 인정합니다(2024.7.1 시행).
- **청약 예치금 판정**: 거주지역(서울·부산 / 기타 광역시 / 기타 시·군)과 통장 예치금을 넣으면, 지원 가능한 최대 전용면적과 면적대별 `충족`·`○○만 원 부족`을 바로 보여 줍니다.
- **참고 정보**: 총점 `XX / 84`와 항목별 막대, 규제지역·그 외 지역의 면적별 가점/추첨 비율 표, 다자녀 특별공급·부부 중복청약 안내.
- **저장**: 입력값은 브라우저 안(localStorage)에만 저장되고 초기화할 수 있습니다.

## 기준

- 「주택공급에 관한 규칙」 **별표 1**(가점제 적용기준)·**별표 2**(민영주택 청약 예치기준금액)·**제28조**(가점제·추첨제 비율), 청약홈 안내를 기준으로 계산합니다.
- 예치금 기준금액(만 원):

  | 전용면적 | 서울·부산 | 기타 광역시 | 기타 시·군 |
  | --- | --- | --- | --- |
  | 85㎡ 이하 | 300 | 250 | 200 |
  | 102㎡ 이하 | 600 | 400 | 300 |
  | 135㎡ 이하 | 1,000 | 700 | 400 |
  | 모든 면적 | 1,500 | 1,000 | 500 |

- 예치금은 **내 주민등록상 거주지역** 기준이며(분양 단지 소재지가 아님), 모집공고일 전날까지 채워야 인정됩니다.
- 공공분양은 일시납이 인정되지 않고 월 납입 인정 한도(25만 원)가 따로 적용되며, 무순위(줍줍) 청약은 통장과 무관합니다.

## 참고

- 계산 결과는 참고용입니다. 실제 가점과 예치금은 입주자모집공고일 기준 세대별 주민등록등본·순위확인서로 확정되니 공고문을 확인하세요.
- 모든 입력은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다. 기본값은 비어 있고, 저장은 그 브라우저의 localStorage에만 남습니다.
